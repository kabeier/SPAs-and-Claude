Set up Claude Code for the homework

Install all four design skills: open a terminal in your project folder (macOS Terminal, Linux, or WSL on Windows) and paste:

curl -fsSL https://kabeier.github.io/SPAs-and-Claude/lecture-2-building-spas/demo-kit/setup-skills.sh | bash
  1. setup-skills.shInstalls all four design skills, complete.
  2. setup-mcps.shAdds the Playwright, Context7 and Chrome DevTools MCPs.
  3. front-end-agent.mdThe reusable front-end sub-agent.
  4. The build promptWhat we pasted into Claude Code.
  5. Example app_outline/Journey, style guide, user stories and wireframes for Liftlog.
