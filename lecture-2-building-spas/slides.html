A single page application loads one HTML page once, then updates parts of it as you click

Traditional website

Every click asks the server for a brand-new page. The screen flashes, scroll resets, anything you typed is gone.

Single page app

The app loads once. Clicking swaps only the part that changed. Instant, smooth, and state survives.

diagrams/L2-01-tech-stack.tldr

Open with: "You won't write this code. You do need to know who's responsible for what. That's how you steer Claude, and how you know where to look when something breaks."

Bottom up:

  • Node runs JavaScript outside the browser (your laptop). Everything below depends on it.
  • npm comes with Node and installs packages (React, Vite, Router). package.json is the shopping list plus scripts like npm run dev.
  • Vite creates the project, runs the fast dev server (localhost:5173), and builds for production.
  • React builds the UI from reusable components and updates only what changed.
  • React Router DOM looks at the URL and decides which component to show, without reloading.

One-liner to repeat: "Node runs your JavaScript, npm manages what your project depends on."

React builds the screen out of components

A component is a reusable piece of UI: a button, a workout card, a navbar.

Build a <WorkoutCard> once, use it on Home and History.

When data changes, React updates only that part of the page.

Not automatically "the best," but popular, flexible, huge ecosystem, and it pairs well with Vite and Router.

// a component is a function that returns UI
function WorkoutCard({ name, date }) {
  return (
    <div className="card">
      <h3>{name}</h3>
      <p>{date}</p>
    </div>
  )
}

Don't teach syntax. The point is "components are LEGO bricks." Tie back to Lecture 1: every box in your wireframe will probably become a component.

diagrams/L2-02-router-shell.tldr

React has no routing built in, so React Router fills that gap: routes, links, navigation, URL params like /workout/42.

The navbar and footer never reload. Only the outlet swaps. That's exactly what they saw in the KSPA radio SPA, which is about 25 lines of a hand-rolled router.

Skills are rulebooks that push Claude past generic AI design

  • frontend-design: Anthropic's official skill. Distinctive type, palette, layout.
  • ui-ux-pro-max: UI/UX rules, component patterns, responsive layout
  • taste: dials for variance and density, bans the "AI slop" defaults
  • design-motion-principles: easing, timing, micro-interactions
