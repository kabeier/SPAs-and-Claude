Install the design skills by hand

Use this page if the one-line install command failed. First check the error table below; most failures are a one-line fix. If yours isn't there, follow the manual install. It doesn't need git, and it ends with exactly the same files as the script.

What you're making

Four skill folders inside your project. Each one has a SKILL.md plus supporting folders, so copy the whole folder, not just the file.

my-project/ └── .claude/ └── skills/ ├── frontend-design/ SKILL.md + 1 file ├── ui-ux-pro-max/ SKILL.md + data/ scripts/ references/ (73 files) ├── taste-skill/ SKILL.md + assets/ library/ ... (29 files) └── design-motion-principles/ SKILL.md + references/ workflows/ (15 files)

If the script printed an error

What you sawWhat to do
'bash' is not recognized, Invoke-WebRequest, or red PowerShell textYou're in PowerShell or Command Prompt. On Windows, open the Ubuntu app (WSL) from the Start menu and run the command there.
git is not installed or git: command not foundMac: run xcode-select --install, click Install, then try again.
WSL / Ubuntu: sudo apt update && sudo apt install -y git
Fedora: sudo dnf install -y git
curl: command not foundWSL / Ubuntu: sudo apt update && sudo apt install -y curl
$'\r': command not found or set: pipefail: invalid optionYou downloaded the script and opened or saved it on Windows, which broke its line endings. Don't run the file; paste the one-line curl ... | bash command instead.
Could not resolve host or Failed to connectNetwork problem. Check your internet or VPN, then try again. On WSL, running wsl --shutdown in PowerShell and reopening Ubuntu often fixes it.
Permission deniedYou're in a folder you don't own. Run cd ~/your-project first. Don't use sudo.
✗ SKILL.md missing for …That skill's GitHub repo moved its files. Use the manual install below and look for the folder that contains SKILL.md.
It worked, but /skills in Claude shows nothingYou ran it in a different folder. Run ls .claude/skills. If you get "No such file", cd into your project and run the command again. Start claude from that same folder.

Manual install: in the terminal

Works on macOS Terminal, Linux, and Windows WSL (the Ubuntu app). Paste one block at a time and wait for it to finish.

  1. Install unzip (Mac and Fedora already have it): 
    sudo apt update && sudo apt install -y curl unzip   # WSL / Ubuntu only
  2. Go to your project folder and create the skills folder. Change my-project to your folder's name: 
    cd ~/my-project
mkdir -p .claude/skills
mkdir -p ~/skill-downloads
  3. Frontend Design 
    curl -L -o ~/skill-downloads/frontend-design.zip https://github.com/anthropics/skills/archive/refs/heads/main.zip
unzip -q -o ~/skill-downloads/frontend-design.zip -d ~/skill-downloads
cp -R ~/skill-downloads/skills-main/skills/frontend-design .claude/skills/
  4. UI UX Pro Max 
    curl -L -o ~/skill-downloads/ui-ux-pro-max.zip https://github.com/nextlevelbuilder/ui-ux-pro-max-skill/archive/refs/heads/main.zip
unzip -q -o ~/skill-downloads/ui-ux-pro-max.zip -d ~/skill-downloads
cp -R ~/skill-downloads/ui-ux-pro-max-skill-main/.claude/skills/ui-ux-pro-max .claude/skills/
  5. Taste 
    curl -L -o ~/skill-downloads/taste-skill.zip https://github.com/Leonxlnx/taste-skill/archive/refs/heads/main.zip
unzip -q -o ~/skill-downloads/taste-skill.zip -d ~/skill-downloads
cp -R ~/skill-downloads/taste-skill-main/skills/taste-skill .claude/skills/
  6. Design Motion Principles 
    curl -L -o ~/skill-downloads/design-motion-principles.zip https://github.com/kylezantos/design-motion-principles/archive/refs/heads/main.zip
unzip -q -o ~/skill-downloads/design-motion-principles.zip -d ~/skill-downloads
cp -R ~/skill-downloads/design-motion-principles-main/skills/design-motion-principles .claude/skills/
  7. Check and clean up. You should see four SKILL.md lines. Then delete the downloads: 
    ls .claude/skills/*/SKILL.md
rm -rf ~/skill-downloads

Manual install: point and click

For when the terminal keeps fighting you. You still need the terminal for one thing: creating .claude, because Finder won't let you name a folder starting with a dot.

  1. Create the skills folder and open it. In your terminal, inside your project folder, run: 
    mkdir -p .claude/skills
    Then open that folder in your file browser:
    Macopen .claude/skillsWindows (WSL)explorer.exe .claude/skillsLinuxxdg-open .claude/skills
    Keep that window open. It's where every skill folder goes.
  2. Download the four ZIP files by clicking each link:
    DownloadAfter unzipping, open this folder and copy the skill folder inside it
    frontend-design ZIPskills-main/skills/ → copy frontend-design
    ui-ux-pro-max ZIPui-ux-pro-max-skill-main/.claude/skills/ → copy ui-ux-pro-max
    This path starts with a hidden folder, see the note below.
    taste-skill ZIPtaste-skill-main/skills/ → copy taste-skill
    design-motion-principles ZIPdesign-motion-principles-main/skills/ → copy design-motion-principles
  3. Unzip each one. On a Mac, double-click it. On Windows, right-click → Extract All.
  4. Copy each skill folder (the whole folder, not just SKILL.md) into the .claude/skills window from step 1.
    Can't see .claude inside the ui-ux-pro-max download? Folders whose names start with a dot are hidden. On a Mac, press Cmd + Shift + . in Finder to show them. On Windows, open File Explorer → View → Show → Hidden items.
  5. Check it. Back in the terminal, in your project folder, run ls .claude/skills/*/SKILL.md. You should see four lines.

Confirm Claude sees them

  1. In your project folder, start Claude Code with claude.
  2. Type /skills. You should see frontend-design, ui-ux-pro-max, design-taste-frontend, and design-motion-principles.

Taste shows up as design-taste-frontend, not taste-skill. That's correct: Claude lists skills by the name written inside their SKILL.md, not by folder name. If Claude was already running when you installed the skills, quit it and start it again.

Want the skills in every project?

Run the one-line install from your home folder instead (cd ~ first). That puts them in ~/.claude/skills, which Claude Code loads in every project.
